# Chelibo

Web del foodtruck Chelibo. Instagram: [@chelibo_](https://www.instagram.com/chelibo_)

- `chelibo/index.html`: la web, lista para abrir en el navegador. Se genera con el script; no la edites a mano.
- `chelibo/src/pagina.html`: la plantilla. El teléfono, los enlaces de WhatsApp y Facebook y las fotos se rellenan en el objeto `CHELIBO`, al principio del `<script>`.
- `chelibo/build.py`: genera la web con `python3 chelibo/build.py`.
- `chelibo/assets/`: logos e iconos. `chelibo/fotos/`: fotos de los platos.
